# lilROI

Marketing ROI Calculator

See what your marketing actually returns. Enter spend, cost per click, your funnel conversion rates, and customer value, and lilROI works out leads, customers, revenue, CPL, CPA, ROAS, and ROI.

Part of [Hot App Summer](https://hotappsummer.netlify.app) by [lilAgents](https://lilagents.com): one small, useful web tool shipped every day through June.

## Run it locally

This is an [Astro](https://astro.build) site.

```bash
pnpm install
pnpm dev
```

To build for production:

```bash
pnpm build
```
